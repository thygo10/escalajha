# Catálogo de Exemplos de Código - Sakai NG

Este diretório contém componentes e snippets de código Angular / PrimeNG validados e testados, alinhados com o **Sakai NG Design System**.

## Estrutura de Exemplos:

- `kpi-card-example/`: Exemplo de cartões de estatísticas (KPIs) com ícones pastel e métricas.
- `table-example/`: Exemplo de tabela de dados (`p-table`) com ordenação, tags de status e ações.
- `form-example/`: Exemplo de formulário responsivo utilizando `pFluid`, `p-inputGroup` e `p-dropdown`.
- `dialog-example/`: Exemplo de modal de confirmação (`p-dialog`) com botões de ação e backdrop.

**Regra para desenvolvedores e Agentes de IA:**  
Ao criar uma nova tela, copie o código destes exemplos como modelo inicial em vez de criar marcação do zero.
